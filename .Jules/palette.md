## 2025-05-22 - Global Accessibility & Tactile Feedback
**Learning:** Implementing a "Skip to content" link and ARIA labels on icon buttons significantly improves the keyboard and screen reader experience without impacting the visual design. Adding subtle scale transitions provides a premium tactile feel.
**Action:** Always include a skip-to-content link, accessible labels for interactive elements, and consistent tactile feedback patterns like `active:scale-95 transition-all`.
