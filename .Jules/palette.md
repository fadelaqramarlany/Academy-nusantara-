## 2025-05-15 - Accessibility and Tactile Feedback Base
**Learning:** Initial audit revealed missing "Skip to content" link, missing ARIA labels on interactive elements like the mobile menu toggle, and inconsistent tactile feedback for navigation links compared to hero buttons.
**Action:** Implement a global "Skip to main content" link, add ARIA attributes for screen readers, and standardize the `active:scale-95 transition-all` pattern for better user response.
