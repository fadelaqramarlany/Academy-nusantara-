## 2026-04-09 - [Enhanced Registration Feedback & Accessibility]
**Learning:** Replacing native `alert()` with an inline, animated success state using Framer Motion significantly improves user delight and maintains context. Providing clear next-step CTAs (like "Mulai Kuis") in the success state reduces cognitive load and guides the user forward.
**Action:** Always prefer inline success states over browser alerts. Pair these with accessibility fundamentals (id/htmlFor) and tactile feedback (active:scale-95) to create a cohesive, high-quality interaction.
