
## 2025-05-22 - Global Accessibility and Tactile Feedback
**Learning:** Adding a "Skip to main content" link and proper ARIA labels to global navigation elements significantly improves the experience for keyboard and screen reader users. Combining this with consistent tactile feedback (`active:scale-95 transition-all`) across all interactive elements creates a more responsive and professional-feeling UI.
**Action:** Always include a skip-link in the root layout and ensure all icon-only or stateful buttons (like mobile menus) have descriptive ARIA attributes and tactile feedback patterns.
