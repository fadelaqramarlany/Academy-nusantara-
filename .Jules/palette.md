## 2025-05-22 - Improving Form Feedback and Accessibility

**Learning:** Replacing native browser alerts with inline success states using animations (like Framer Motion) significantly improves user perceived quality and flow. Additionally, proper label-input association is a common but critical accessibility gap in many forms.

**Action:** Always check for `htmlFor` and `id` pairing in forms. Use `AnimatePresence` for smooth feedback transitions.
