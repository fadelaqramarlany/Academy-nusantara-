# Palette Journal

## 2026-04-09 - Replacing native alerts with state-driven success UI
**Learning:** Native `alert()` calls disrupt the user flow and feel disconnected from the modern UI. State-driven success messages with Framer Motion provide immediate, delightful feedback that keeps the user within the application context.
**Action:** Prioritize replacing browser-native dialogs with animated, accessible inline success states that offer clear follow-up actions (e.g., "Send again" or "Return to home").
