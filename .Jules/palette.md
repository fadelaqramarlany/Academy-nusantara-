## 2025-05-23 - Enhance Registration UX and Accessibility
**Learning:** Replacing native browser `alert()` with inline state-based success messages provides a more seamless and professional user experience. Proper `id`/`htmlFor` linking and tactile feedback (`active:scale-95`) significantly improve accessibility and perceived responsiveness.
**Action:** Prioritize inline success states and consistent tactile feedback in all interactive components. Ensure all form fields are correctly labeled for screen readers.
