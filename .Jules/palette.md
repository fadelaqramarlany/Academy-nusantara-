## 2026-04-09 - [Inline Form Success States]
**Learning:** Replacing native browser `alert()` with inline animated success states significantly improves the user's flow and keeps them engaged with the application UI. Using Framer Motion for these transitions adds a touch of delight.
**Action:** Always prefer inline success messages over `alert()` for form submissions. Ensure a "Reset" or "Send Again" option is provided to maintain usability.

## 2026-04-09 - [Tactile Button Feedback]
**Learning:** Adding subtle scale animations (`active:scale-95`) to buttons provides immediate tactile feedback, making the interface feel more responsive and high-quality.
**Action:** Implement `active:scale-95` and `transition-all` on primary action buttons.
