## 2025-05-15 - [Inline Success State over Native Alerts]
**Learning:** Replacing native browser alerts with inline success states significantly improves the user journey by maintaining context and providing a more modern, integrated feel. Framer Motion can be used for smooth entry animations even in surgical micro-UX improvements.
**Action:** Prioritize inline feedback for form submissions and use MotionDiv for entrance effects when dependencies allow.

## 2025-05-15 - [Surgical Form Refactoring]
**Learning:** Using a `.map` pattern for repetitive form fields in React components helps keep the implementation concise, allowing for significant accessibility and UX upgrades (like `id`/`htmlFor` linking and tactile feedback) while staying under strict line count constraints (e.g., 50 lines).
**Action:** Look for opportunities to consolidate repetitive JSX into data-driven loops when refactoring for UX or accessibility.
