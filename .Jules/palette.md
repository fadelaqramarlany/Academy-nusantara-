## 2026-04-09 - Transitioning from Alerts to Inline Success States
**Learning:** Browser `alert()` calls are disruptive and break the visual flow of modern, highly-animated interfaces like Academy Nusantara. Inline success states, especially when combined with Framer Motion, provide a much smoother and more professional user experience.
**Action:** Replace native `alert()` notifications with conditional rendering and Framer Motion animations for form submissions. Ensure the success state provides clear next steps (e.g., anchor links to key sections) to maintain user momentum.
